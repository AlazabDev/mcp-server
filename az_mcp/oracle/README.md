# Oracle Cloud Infrastructure MCP

## الغرض
إدارة خوادم وموارد OCI: Compute وVolumes وNetworking وHealth والموارد المرتبطة.

## Endpoint المقترح
`mcp.alazab.com/oracle`

## الاستخدام داخل العزب
يُستخدم هذا المجلد كمرجع وتشغيل وتطوير للتكامل الخاص بـ **Oracle Cloud Infrastructure** داخل منظومة Alazab MCP.

## متغيرات البيئة
> تحفظ القيم الفعلية في `.env` ولا توضع داخل هذا الملف.

```env
OCI_CONFIG_FILE=
OCI_PROFILE=alazab
OCI_REGION=
```

## الأدوات الأساسية المقترحة
- `list_instances`
- `get_instance`
- `inspect_volumes`
- `inspect_network`
- `instance_action`
- `get_metrics`
- `inspect_health`

## قواعد التطوير
- لا يتم تكرار Business Logic موجود أصلًا في النظام المصدر.
- الـMCP يكون طبقة أدوات واضحة وخفيفة فوق الـAPI أو الخدمة الأصلية.
- كل Tool يجب أن يكون له اسم واضح وInput/Output Schema محدد.
- توثق أي إضافة جديدة في هذا الملف.
- عند وجود عمليات قراءة وكتابة، يفضل الفصل بينها منطقيًا داخل الأدوات.
