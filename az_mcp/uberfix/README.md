# UberFix MCP

## الغرض
إدارة طلبات الصيانة والحالات والفنيين والمواقع والمرفقات والتعليقات والفواتير والمصروفات عبر UberFix.

## Endpoint المقترح
`mcp.alazab.com/uberfix`

## الاستخدام داخل العزب
يُستخدم هذا المجلد كمرجع وتشغيل وتطوير للتكامل الخاص بـ **UberFix** داخل منظومة Alazab MCP.

## متغيرات البيئة
> تحفظ القيم الفعلية في `.env` ولا توضع داخل هذا الملف.

```env
UBERFIX_GATEWAY=
UBERFIX_API_KEY=
UBERFIX_BASE_URL=
```

## الأدوات الأساسية المقترحة
- `create_maintenance_request`
- `get_request_status`
- `transition_request_stage`
- `add_request_note`
- `cancel_request`

## قواعد التطوير
- لا يتم تكرار Business Logic موجود أصلًا في النظام المصدر.
- الـMCP يكون طبقة أدوات واضحة وخفيفة فوق الـAPI أو الخدمة الأصلية.
- كل Tool يجب أن يكون له اسم واضح وInput/Output Schema محدد.
- توثق أي إضافة جديدة في هذا الملف.
- عند وجود عمليات قراءة وكتابة، يفضل الفصل بينها منطقيًا داخل الأدوات.
