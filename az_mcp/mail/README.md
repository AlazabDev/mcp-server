# Mail MCP

## الغرض
توحيد البحث والقراءة والمرفقات والمسودات والإرسال والرد عبر Outlook/Exchange وGmail.

## Endpoint المقترح
`mcp.alazab.com/mail`

## الاستخدام داخل العزب
يُستخدم هذا المجلد كمرجع وتشغيل وتطوير للتكامل الخاص بـ **Mail** داخل منظومة Alazab MCP.

## متغيرات البيئة
> تحفظ القيم الفعلية في `.env` ولا توضع داخل هذا الملف.

```env
MAIL_PROVIDER=
MAIL_ACCOUNT=
MAIL_CLIENT_ID=
MAIL_CLIENT_SECRET=
```

## الأدوات الأساسية المقترحة
- `search_mail`
- `get_message`
- `get_thread`
- `list_attachments`
- `create_draft`
- `send_message`
- `reply_message`

## قواعد التطوير
- لا يتم تكرار Business Logic موجود أصلًا في النظام المصدر.
- الـMCP يكون طبقة أدوات واضحة وخفيفة فوق الـAPI أو الخدمة الأصلية.
- كل Tool يجب أن يكون له اسم واضح وInput/Output Schema محدد.
- توثق أي إضافة جديدة في هذا الملف.
- عند وجود عمليات قراءة وكتابة، يفضل الفصل بينها منطقيًا داخل الأدوات.
